## The Operator says

I once watched a grown man retype a forty-character Wi-Fi password from one window to another. Three times. I wrote it in the luser list in very neat letters.

Shortcut keys are how people who use computers all day get home on time. Hold one key, tap another, and something that took ten clicks happens instantly. Learn the first six in this lesson and you'll be faster than most of the office. Learn the rest and I start worrying about my job.

## The Mender's way

A **shortcut key** is two or three keys pressed together to do something quickly.

### How to press a shortcut

When you see <kbd>Ctrl</kbd> + <kbd>C</kbd>:

1. Press and **hold** the first key (<kbd>Ctrl</kbd>, bottom-left of the keyboard).
2. While still holding it, **tap** the second key (<kbd>C</kbd>) once.
3. Let go of both.

The <kbd>Windows</kbd> key has the Windows logo ⊞, between <kbd>Ctrl</kbd> and <kbd>Alt</kbd>. The <kbd>Shift</kbd> key has an upward arrow.

### Copy, cut and paste

First **select** it: drag across text so it's highlighted (Lesson O), or click once on a file.

- **Copy** keeps a copy ready to put somewhere else. The original stays put.
- **Cut** takes it away, ready to put somewhere else.
- **Paste** puts it down where your cursor is.

Copied things wait in the **clipboard**, which holds one thing at a time.

### The shortcuts worth learning

The first six are the ones you'll use every day.

| Keys | What it does |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>C</kbd> | **Copy** the selected text or file |
| <kbd>Ctrl</kbd> + <kbd>X</kbd> | **Cut** the selected text or file |
| <kbd>Ctrl</kbd> + <kbd>V</kbd> | **Paste** it where the cursor is |
| <kbd>Ctrl</kbd> + <kbd>Z</kbd> | **Undo** the last thing you did |
| <kbd>Ctrl</kbd> + <kbd>S</kbd> | **Save** the document you're working on |
| <kbd>Alt</kbd> + <kbd>Tab</kbd> | **Switch** between open windows. Hold <kbd>Alt</kbd>, tap <kbd>Tab</kbd> to move along, let go to choose |
| <kbd>Ctrl</kbd> + <kbd>Y</kbd> | **Redo**: put back what you just undid |
| <kbd>Ctrl</kbd> + <kbd>A</kbd> | Select **all** (all the text, or all the files in a folder) |
| <kbd>Ctrl</kbd> + <kbd>P</kbd> | **Print** (Lesson P) |
| <kbd>Ctrl</kbd> + <kbd>F</kbd> | **Find** a word on the page or in the document |
| <kbd>Ctrl</kbd> + <kbd>+</kbd> / <kbd>Ctrl</kbd> + <kbd>-</kbd> | **Zoom** in or out (bigger or smaller) in the browser and many apps. <kbd>Ctrl</kbd> + <kbd>0</kbd> resets it |
| <kbd>Windows</kbd> | Open (or close) the **Start** menu |
| <kbd>Windows</kbd> + <kbd>D</kbd> | Show the **desktop**. Press again to bring the windows back |
| <kbd>Windows</kbd> + <kbd>E</kbd> | Open **File Explorer** |
| <kbd>Windows</kbd> + <kbd>L</kbd> | **Lock** the computer. Use it every time you walk away |
| <kbd>Windows</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> | Take a **screenshot** (a picture of the screen) |
| <kbd>Windows</kbd> + <kbd>V</kbd> | **Clipboard history**: everything you've copied recently |

For zooming in, the <kbd>=</kbd> key (with the + on it) works; no <kbd>Shift</kbd> needed.

### Taking a screenshot

A **screenshot** is a picture of your screen, handy for showing someone a problem (Lesson T).

1. Press <kbd>Windows</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd>. The screen dims and a small bar appears at the top.
2. Drag a box around the part you want, with the left mouse button held down.
3. Let go. The picture is copied to the clipboard. Paste it with <kbd>Ctrl</kbd> + <kbd>V</kbd> into an email or document. Windows also saves a copy in **Pictures**, then **Screenshots**.

### Clipboard history

Clipboard history remembers your last few copies.

1. Press <kbd>Windows</kbd> + <kbd>V</kbd>.
2. The first time, click **Turn on**.
3. From then on, <kbd>Windows</kbd> + <kbd>V</kbd> shows a list of recent copies. Click one to paste it.

### On Windows (right-click instead)

Forgot the shortcut? Right-click the selected text or file. **Copy**, **Cut** and **Paste** are in that menu (in File Explorer, as small icons along its top).

### On Android (your phone)

Phones have no <kbd>Ctrl</kbd> key. Use a **long-press** instead: touch and hold for a second.

1. **Long-press** a word. It's highlighted, with a little handle at each end.
2. Drag the handles to cover all the words you want.
3. Tap **Copy** in the small menu that appears above.
4. Go to where you want the words, for example a message box.
5. **Long-press** inside the box, then tap **Paste**.

Most phone keyboards also have a **clipboard** icon in their top row, showing recent copies.

## Do it now

1. Open a web page, and open Notepad (**Start**, type `Notepad`).
2. On the web page, select one sentence and press <kbd>Ctrl</kbd> + <kbd>C</kbd>.
3. Press <kbd>Alt</kbd> + <kbd>Tab</kbd> to reach Notepad.
4. Click in Notepad; press <kbd>Ctrl</kbd> + <kbd>V</kbd>.
5. Press <kbd>Ctrl</kbd> + <kbd>Z</kbd> to undo, then <kbd>Ctrl</kbd> + <kbd>Y</kbd> to bring it back.
6. Press <kbd>Windows</kbd> + <kbd>L</kbd> to lock the computer, then sign back in.

You've done it when the sentence is in Notepad and you typed none of it. Close Notepad without saving.

## Quiz

```quiz
- q: You want to put an address from an email into a letter. What's the best way?
  options:
    - Read it carefully and type it out again
    - Select it, Ctrl + C, click in the letter, Ctrl + V
    - Take a photo of the screen with your phone
  answer: 1
  why: Copy and paste moves the exact text across in seconds, with no typing mistakes.
- q: You're about to walk away from the computer for a few minutes. Which shortcut should you press?
  options:
    - Windows + D
    - Windows + L
    - Ctrl + S
  answer: 1
  why: Windows + L locks the computer, so nobody can use it until you type your PIN or password. Windows + D only hides the windows.
- q: How do you do a shortcut like Ctrl + C?
  options:
    - Hold Ctrl, tap C, then let go of both
    - Press C, then Ctrl, one after the other
    - Press both as hard as you can
  answer: 0
  why: Hold the first key, tap the second, then let go. Pressing them one after the other just types a letter.
```

## Scribble watch

The Scribble lives in clipboards. Copy a password or bank number and it stays there, ready to be pasted somewhere it shouldn't. Afterwards, copy something harmless (a single word). If you use clipboard history, press <kbd>Windows</kbd> + <kbd>V</kbd>, click the **⋯** next to the private item, and choose the bin icon to delete it.
